Filter Impact: Filtered vs ALL (Filter Count = Total Docs)

Comparison Scenarios:

  • 100K Docs: Exp1 (ALL) vs Exp2 (1K filter) vs Exp3 (10K filter)
  • 1K Docs: Exp6 (ALL) - baseline
  • 10K Docs: Exp7 (ALL) - baseline

Key Findings:

  • 100K/ALL (20ms) vs 100K/1K (21ms): Only 1ms overhead with filtering
  • 100K/ALL (20ms) vs 100K/10K (19ms): 10K filter is actually 1ms faster!
  • Filtering overhead is negligible when filter count is small relative to total docs
  • Smaller doc sets (1K, 10K) with ALL filter are fastest: 16-17ms
